## Exact code changes (copy/paste)

### 1) `build/space/backend/routers/scans.py`

Replaced UUID Query param with a string alias and coercion so client-side `"null"` or empty values do not trigger validation errors.

```py
async def list_scans(
    # Accept stringy query values (including "null" or empty) and coerce to UUID|None
    patient_id_raw: str | None = Query(None, alias="patient_id"),
    limit: int = Query(50, ge=1, le=200), offset: int = Query(0, ge=0),
    user: User = Depends(get_current_user),
    session: AsyncSession = Depends(get_session),
):
    # Normalize common client-side encodings for "no patient": null, "null", ""
    patient_id: uuid.UUID | None
    if patient_id_raw is None or patient_id_raw == "null" or patient_id_raw == "":
        patient_id = None
    else:
        try:
            patient_id = uuid.UUID(patient_id_raw)
        except Exception:
            raise AppError(422, "Invalid patient_id")

    if patient_id is None:
        scans = await scan_service.list_all_scans(session, user, limit, offset)
    else:
        scans = await scan_service.list_scans(session, user, patient_id, limit, offset)

    return [ScanOut.from_scan(s) for s in scans]
```

## Commands to finish local setup (run these in the project root)

1. Activate backend venv (if not already active)

```bash
python3 -m venv backend/venv
source backend/venv/bin/activate
pip install -r build/space/requirements.txt
```

2. Run Alembic migrations to create tables (required; run from project root):

```bash
# Option A: run from build/space where alembic config lives
cd build/space
alembic upgrade head

# Option B: from project root (explicit config path)
PYTHONPATH=build/space alembic -c build/space/alembic.ini upgrade head
```

3. Create an admin user (interactive):

```bash
PYTHONPATH=build/space python build/space/backend/scripts/create_admin.py --email admin@example.com --name "Admin"
# follow prompts to enter a password (>=10 chars)
```

4. Start the backend (reloadable):

```bash
PKILL -f uvicorn || true
PYTHONPATH=build/space uvicorn backend.main:app --reload --port 7860 --reload-dir build/space/backend
```

5. Ensure the frontend uses local API and restart Vite:

```bash
# ensure frontend/.env.local contains:
echo 'VITE_API_BASE_URL=http://127.0.0.1:7860' >> frontend/.env.local
cd frontend
npm install
npm run dev
```
